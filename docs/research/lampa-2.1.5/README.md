# Lampa 2.1.5: исследование (iOS, com.lampa.photo)

Статический анализ IPA `com.lampa.photo-2.1.5` (SHA-256 `ee002a39…ab7e91`). Приложение не запускалось.

## Содержимое

- `reports/LAMPA_ANALYSIS.md` — структура пакета, модули, путь работы, сеть, аналитика, покупки.
- `reports/CAMERA_FSM_DECODE.md` — восстановление машины состояний камеры.
- `reports/CAMERA_FSM_TABLE.md` — таблица переходов состояние × событие с пометками уверенности.
- `decompiled/functions/` — псевдокод Ghidra 12.1.4 (143 функции, включая `transition`, `setState`, координатор). Это вывод декомпилятора, не исходный Swift.
- `decompiled/decompile-index.json` — индекс функций: адрес, имя, диапазон, хеш.
- `rea/` — сводки REA: инспекция артефакта, инвентаризация пакета, журнал запуска Ghidra, диагностика.

## Что не включено

- Сам IPA и распакованные ассеты (бинарники, LUT, видео, DNG, шрифты) принадлежат владельцу приложения.
- Строковый дамп бинарника (4.5 МБ) и сырые JSON инспекции: воспроизводятся командами REA из отчётов.
- Файлы LUT пользователя: они не публикуются.

## Ограничения

Псевдокод и выводы о поведении — гипотезы по символам, структуре и выборочной декомпиляции. Подтверждение нужно на устройстве.
