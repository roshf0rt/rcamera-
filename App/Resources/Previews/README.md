# Картинки для карточек пресетов

Здесь лежат готовые карточки пресетов: `preset-1.png` … `preset-10.png`, номер как у пресета.

- PNG 828 × 504 px (2×), с прозрачными углами; сделаны из SVG-карточек `RCamera_Icons_and_Filters/FilterCardsSVG` и отрисованы через браузер.
- На карточке уже написаны название и слова (например, «Mono · Contrast»), поэтому в карусели подписи поверх картинки не рисуются.
- Если файла нет, карточка рисует пейзаж и прогоняет его через LUT, а подписи строятся по LUT.
- Переименованный пресет сохранит старое название на картинке: картинка не обновляется.
- JPEG `preset-N.jpg` тоже принимается, если PNG нет.

Шрифт на картинках — системный sans-serif из браузера (не SF Pro). Для точного совпадения с iOS перерисуйте карточки в Xcode или на Mac.
