# Картинки для карточек пресетов

Положите сюда по одной картинке на пресет. Имя файла — `preset-<номер>.jpg`, номер как у пресета
(`preset-1.jpg` … `preset-10.jpg`). Если файла нет, карточка рисует пейзаж и прогоняет его через LUT.

Формат:
- JPEG, sRGB, без альфа-канала;
- 800 × 500 px (соотношение 16:10, как карточка);
- одна и та же сцена и кадрирование для всех десяти пресетов, чтобы разница была только в LUT;
- качество 85–90 %.

Слова под картинкой (Warm, Faded и т. д.) по-прежнему считаются по самому LUT, а не по картинке.
