# rcamera

Своя реализация камеры в стиле Lampa 2.1.5. Пока здесь только ядро: машина состояний записи и настроек.

## Что есть

- `Sources/CameraCore` — чистая логика без iOS-зависимостей. Принимает события, возвращает эффекты, которые выполняет вызывающий код.
- `Tests/CameraCoreTests` — 32 теста, по одному на каждую строку таблицы переходов.

## Запуск

```sh
swift build
swift test
```

Нужен Swift 6.x. Проверено на Swift 6.2.1 под Linux.

## Откуда поведение

Переходы восстановлены из декомпиляции Lampa 2.1.5 (Ghidra 12.1.4). Таблица с пометками уверенности — в отчёте, который лежит вне репозитория. Где таблица не подтверждена, выбор сделан вручную и отмечен комментариями в коде:

- эффекты `startVideoRecording` и `stopVideoRecording` для `startRecordingTap` и `stopRecordingTap` (в исходнике не видны);
- выход из записи через `videoRecordingDidFinish` — переход в `idle` с сохранением режима;
- `updateVideoConfiguration` принимается и во время записи — так в таблице, защиты в коде не видно.

## Что не скопировано

Из IPA не взято ничего, кроме наблюдений о поведении: ни код, ни LUT-таблицы, ни шрифты, видео, DNG-файлы, ассеты. Всё написано заново.

## Что ещё нужно

1. Захват с камеры через AVFoundation и исполнитель эффектов. Нужен Xcode и iPhone.
2. Обработка кадра на Metal: цветовые профили, зерно, halation. Ассеты делаются заново.
3. UI-слой.
4. Проверка переходов на устройстве: таблица пока не подтверждена динамически.
